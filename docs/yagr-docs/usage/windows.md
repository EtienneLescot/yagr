# Windows

Yagr runs natively on Windows through Node.js and the local shell selected by the runtime.

## Requirements

- Node.js 20+
- Git
- A configured model provider or account-backed provider session

## Usage

```powershell
yagr setup
yagr webui
```

If shell commands fail, verify that your terminal can run the same command directly and that the project path is accessible from the current Windows session.
