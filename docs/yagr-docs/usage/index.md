# Usage

## Run A Prompt

```bash
yagr "inspect this repository and summarize the main modules"
```

## Start The Web UI

```bash
yagr webui
```

## Configure The Runtime

```bash
yagr setup
yagr llm setup
```

## Telegram Gateway

```bash
yagr telegram setup
yagr telegram start
```

Yagr stores its runtime state under `YAGR_HOME` or the platform default home directory.
